# 1chooo.com

The open-source published content from [1chooo.com](https://1chooo.com): landing, bio, projects, terms, thoughts, notes, episodes, their MDX content, and presentation components.

- Next.js v16 App Router & React Server Components
- MDX (Rust compiler) & Shiki for content parsing
- Tailwind CSS v4 & Motion for styling and animations
- All content is statically rendered; no admin or service code is included.

## Deliberately excluded

This repository contains no admin interface, authenticated service, API route, database schema, migration, credentials, environment file, analytics identifier, unpublished draft, Cursor usage data, or internal skill document. Photo blocks that relied on private data services are deliberately rendered as empty placeholders.

This art-inspired design comes from [shud.in](https://shud.in).
